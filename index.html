ConvoKit: Conversational Analysis Toolkitt

This toolkit contains tools to extract conversational features and analyze social phenomena in conversations, using a single unified interface inspired by (and compatible with) scikit-learn. Several large conversational datasets are included together with scripts exemplifying the use of the toolkit on these datasets. The latest version is 4.0.0 (released Nov. 3, 2025); follow the project on GitHub to keep track of updates.
